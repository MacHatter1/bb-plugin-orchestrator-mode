# Orchestrator Mode 0.1.3

This patch removes the stray edge inside the composer when orchestrator mode is enabled.

## Composer fix

- Remove the decorative inset border from editable draft text.
- Keep the mode toggle, status banner and confirmation toast unchanged.
- Preserve draft content for existing threads and new-thread defaults, including on/off transitions.

Worker execution, delegation and watchdog behaviour are unchanged from 0.1.2. No dependency or SDK upgrade is included.

## Upgrade notes

Update to 0.1.3 using your usual plugin update method. For a local path installation, rebuild the checkout and reload the plugin so the running frontend picks up the fix.
